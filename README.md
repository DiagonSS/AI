# 3D калькулятор ухода за газоном

Веб-приложение рассчитывает стоимость обслуживания газона и изгороди по тарифам Манчестера 2025 года и одновременно отображает участок в лёгкой 3D-сцене Three.js. Геометрия газона и изгороди обновляется при каждом изменении формы.

## Возможности визуализации
- Интерактивная сцена с орбитальным управлением камерой и мягким освещением.
- Реалистичное распределение изгороди по периметру с использованием инстансинга для высокой производительности.
- Динамическая инфографика с размерами участка, площадью и процентом покрытия изгородью.
- Садовая дорожка и улучшенный материал газона для быстрого восприятия глубины.

## Как запустить локально
1. Убедитесь, что у вас установлен Python 3.
2. В корне проекта выполните команду:
   ```bash
   python -m http.server 5173
   ```
3. Откройте браузер и перейдите по адресу [http://localhost:5173](http://localhost:5173). Страница `index.html` загрузится автоматически.
4. Изменяйте значения в форме — расчёты и визуализация обновляются сразу без дополнительной сборки.

> Альтернатива: вы можете просто открыть `index.html` двойным кликом. Однако локальный сервер избавляет от ограничений безопасности браузера при загрузке модулей.

## Проверка 3D визуализации
- После загрузки страницы убедитесь, что зелёный газон и изгородь отображаются и реагируют на вращение/масштабирование.
- Измените параметры площади и периметра: геометрия газона и объём изгороди будут подстраиваться под новые размеры.
- Если 3D-сцена не отображается, откройте консоль браузера (F12) — там появится сообщение об ошибке, которое поможет диагностировать проблему.
